# Memory Router

See `vault-template/Memory Router.md` for the actual routing table you'd customize. The short version:

- Classify every new piece of information before writing it anywhere.
- Route it to the specific place it belongs (a project folder, a daily log, a personal-context note).
- **When genuinely unsure, drop it in `Inbox/` — never guess inside an existing note.** A wrong guess corrupts a real memory; a wrong guess in the Inbox just needs re-filing.
- One note = one responsibility (SRP). If a note is doing two jobs, split it.
- No duplication — link to a fact instead of copying it (this is also why `bin/tdruid-status` exists: a fact that would otherwise get copy-pasted into multiple scripts should live in exactly one place).
- Log the routing decision in your daily log so the system stays auditable — you should always be able to answer "why did this end up here."
