# 🧭 Memory Router

Before writing anything new to the vault, classify it and send it to the right place. **When unsure, use `Inbox/` — never guess inside an existing note.** Guessing wrong corrupts a real memory; a wrong guess in the Inbox just needs to be re-filed later.

## Categories (adapt to your own life/work)

| Content is about... | Goes in... |
|---|---|
| A specific project | `Projects/{{ProjectName}}/` |
| You (the human) — preferences, goals, relationships | `Memories/` or wherever you keep personal-context notes |
| A fleeting idea, unclear where it belongs | `Inbox/` |
| A daily record of what happened | `Conversas/YYYY-MM-DD.md` (or your own daily-log folder name) |
| A durable behavioral correction ("don't do X, do Y") | Directly in the relevant hub note, or in your agent's own long-term memory system if it has one separate from the vault |

## Rules

- **One note = one responsibility (SRP).** If a note is doing two jobs, split it.
- **No duplication.** If a fact already lives somewhere, link to it — don't copy it.
- **No orphans.** Every new note links back to your brain hub (`🧠 Brain`), or to a project hub that's connected to it.
- **Log the routing decision.** When you file something, say so in the daily log — it's how the system stays auditable.
